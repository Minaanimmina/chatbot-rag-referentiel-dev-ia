# Assistant RNCP Développeur IA

Bienvenue ! Je suis votre assistant pour analyser la couverture de votre projet par rapport au référentiel RNCP Développeur en IA.

## Comment obtenir une analyse précise ?

Décrivez votre projet en mentionnant :
- Les **technologies utilisées** (FastAPI, Docker, LightGBM...)
- Les **tâches réalisées** (entraînement d'un modèle, déploiement d'une API, monitoring...)
- Les **outils DevOps** (CI/CD, tests automatisés, versionnement...)

## Exemple de bonne description :
> "Mon projet entraîne un modèle LightGBM sur des données BAAC, l'expose via une API FastAPI Dockerisée, avec des tests pytest et un pipeline CI/CD GitHub Actions."
